# ZOVEX PC

סביבת שולחן עבודה בסגנון Windows 11 לאנדרואיד ARM64, מעל Wine ו-Box64.
הממשק בעברית ו-RTL; הטרמינל וחלונות התוכנות נשארים באנגלית ו-LTR.

**מצב: שלב 1 — בדיקת חומרה.** אין עוד מנוע Windows בפרויקט.

## מה המערכת עושה כרגע

נפתחת, מודדת את המכשיר ואומרת מה הוא באמת מסוגל להריץ:

- האם הארכיטקטורה היא `arm64-v8a` (Box64 דורש תהליך 64-bit)
- האם המכשיר מתיר מיפוי הרצה מהאחסון (W^X) — קובע אם צריך proot
- גרסת Vulkan, שם ה-GPU ושם הדרייבר
- `timelineSemaphore` — שער ל-DXVK 2.x
- `descriptorIndexing` — שער ל-VKD3D-Proton, כלומר ל-DirectX 12
- כמות זיכרון

הכל נמדד, לא מנוחש. אם לא הצלחנו להוכיח יכולת בבדיקה, היא מדווחת כחלקית
או כלא נתמכת.

## בנייה

הבנייה דרך GitHub Actions: כל push לכל ענף מפיק APK ב-Artifacts.

מקומית נדרש Android Studio עם NDK 27 ו-CMake 3.22:

```bash
./gradlew :app:assembleDebug
```

## רישוי

הפרויקט לא מצרף ולא יצרף Windows, מפתחות מוצר, DLL-ים קנייניים, גופני
Microsoft קנייניים או קבצי משחקים. ראה `docs/DESIGN.md` לגבי הגופנים
והאייקונים שבהם אנחנו כן משתמשים, ו-`docs/FEASIBILITY.md` לגבי מה שמוגדר
כיעד ומה שמוגדר כניסוי.
