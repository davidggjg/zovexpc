# היתכנות — מה מובטח, מה ניסיוני, מה לא

המסמך הזה קובע מה מותר להבטיח למשתמש. אין להכריז על תמיכה ברכיב לפני
שהוא עבר בדיקה על חומרה אמיתית.

## מובטח (הבסיס שעליו בונים)

| יכולת | הערה |
|---|---|
| Wine + Box64 על ARM64, בלי root ובלי רישיון Windows | הבסיס |
| `cmd.exe`, קובצי `.bat` / `.cmd`, תוכנות console | המקרה הכי אמין. לא נוגע ב-GPU |
| הרצת EXE ו-MSI, Wine Prefix מתמשך | נשמר בין הפעלות |
| אינטרנט מלא בתוך הסביבה | `winsock` ממופה ל-sockets של אנדרואיד |
| `C:\` וירטואלי, Registry, Explorer, Taskbar, Task Manager | UI משלנו מעל ה-prefix |
| ממשק עברית RTL | הטרמינל נשאר LTR בכוונה |

## דורש עבודה ייעודית

- **תעודות TLS.** Wine לא רואה את מאגר התעודות של אנדרואיד. בלי הזרקת
  CA bundle ל-prefix, כל תוכנה שקוראת ל-API חוזרת עם
  `certificate verify failed`. חייב להיכנס בשלב 2.
- **Firefox תחת Wine.** עובד, אבל x86 דרך Box64 גובה כ-40-50% מהמעבד.
  לכן מתוכננים שני דפדפנים: דפדפן מהיר מבוסס אנדרואיד שמוריד ישר לכונן
  `C:`, ו-Firefox "אמיתי" לחוויה המלאה.
- **PowerShell.** דורש .NET מלא מעל Wine Mono. חלקי. best effort בלבד.
- **.NET console** — דורש Wine Mono ולעיתים כיול לכל תוכנה.

## ניסיוני — לא להבטיח

- **DirectX 12 / VKD3D-Proton.** דורש פיצ'רי Vulkan שב-Adreno עם Turnip
  חלקם חסרים או באגיים. האפליקציה בודקת `descriptorIndexing` ומדווחת
  "ניסיוני" גם כשהוא קיים.
- **משחקים כבדים (לדוגמה GTA V).** זיכרון, throttling תרמי אחרי 10-15
  דקות, ו-launcher / anti-cheat. ניסוי, לא יעד מוצר.
- **Electron (דיסקורד וכדומה).** כרום שלם בתוך Wine בתוך Box64. ירוץ כבד.
  לא בשלב ראשון.

## לא אפשרי כפי שתוכנן

- **QEMU עם Windows אמיתי.** אנדרואיד לא נותן לאפליקציה רגילה גישה
  ל-KVM, ולכן זו אמולציה בתוכנה — אחוזים בודדים מהביצועים. לא שימושי
  למשחקים ולא מוצדק גם כמודול אופציונלי בשלב הזה.
- **הפצת Windows, מפתחות או DLL-ים קנייניים.** המשתמש מספק מה שיש לו
  זכות להשתמש בו.

## החלטות ארכיטקטורה שנקבעו

1. **הרנטיים בתהליך OS נפרד** (`:wine` במניפסט). קריסה של Wine או Box64
   לא מפילה את הממשק.
2. **arm64-v8a בלבד.** Box64 דורש תהליך מאחסן 64-bit, אז אין
   `armeabi-v7a`.
3. **W^X נקבע במדידה**, לא לפי גרסת אנדרואיד — מדיניות OEM ו-SELinux
   משתנה בין מכשירים. ראה `exec_probe.cpp`.
