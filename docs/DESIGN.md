# עיצוב — דמיון ל-Windows 11 בלי נכסים של Microsoft

הפרויקט לא מצרף גופנים, אייקונים או קבצי תמה קנייניים של Microsoft. אסור
לצרף `segoeui.ttf`, אייקוני Fluent קנייניים או קבצי תמה שחולצו מ-Windows.
מה שכן בשימוש נותן תוצאה כמעט זהה:

| רכיב | מה בשימוש | רישיון |
|---|---|---|
| גופן לטיני | Selawik — מטרית-תואם ל-Segoe UI | MIT, מ-Microsoft |
| גופן עברי | Heebo | OFL |
| גופן טרמינל | Noto Sans Mono + Miriam Mono CLM | OFL / GPL+FE |
| אייקונים | Fluent UI System Icons | MIT, מ-Microsoft |
| Mica / Acrylic | מימוש שלנו ב-`RenderEffect` / Vulkan | — |
| צבעים, פינות, אנימציות | טוקנים ב-`ui/Theme.kt` | — |

## עברית

- כל ממשק ZOVEX — תפריט התחל, הגדרות, סייר, תפריט הקשר, סל מחזור, מנהל
  משימות, הודעות שגיאה — עברית ו-RTL. זה מה שהמשתמש רואה כמעט כל הזמן.
- הטרמינל וחלונות תוכנות Windows נשארים LTR ואנגלית. ה-shell מעמיד
  `LayoutDirection.Rtl` גלובלית; כל חלון תוכנה חייב לבטל אותה אצלו.
- בטרמינל: UTF-8 ו-`chcp 65001` כברירת מחדל בכל prefix חדש, ו-BiDi דרך
  ICU של אנדרואיד — טוב יותר ממה ש-conhost של Windows עושה בעברית.

## מגע

Windows תוכנן לסמן של פיקסל אחד. זו הנקודה שבה סביבות כאלה נכשלות. לכן:

- **לחיצה ארוכה = קליק ימני**; שתי אצבעות = גלילה
- **אזור מגיעה 24dp** גם כשהאלמנט נראה דק יותר (למשל גרירת שוליים של חלון)
- **זכוכית מגדלת** בזמן נגיעה, לדיוק בתוך תוכנות PC
- **טראקפד וירטואלי מרחף** לתוכנות שדורשות סמן אמיתי
- **מקלדת וגיימפד וירטואליים** עם פריסה לכל משחק
- ברירת מחדל: הממשק שלנו בגדלי מגע, התוכנות ב-DPI scaling 150%
